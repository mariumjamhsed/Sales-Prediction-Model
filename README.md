Sales Prediction Model

This project builds a Linear Regression model to predict sales using historical sales data. The dataset is preprocessed by handling categorical variables through one-hot encoding and splitting the data into training and testing sets. The model is trained to learn the relationship between features such as Unit Price, Units Sold, Country, Region, and Item Type and the target variable.

The model's performance is evaluated using Mean Absolute Error (MAE), Root Mean Squared Error (RMSE), and R² Score, providing insights into its prediction accuracy and ability to explain the variation in sales. This project demonstrates the complete machine learning workflow, including data preprocessing, model training, prediction, and performance evaluation.
